# 1.7.0 unified Minecraft release

Date: 2026-10-10. Minecraft 26.1.x and 26.2 now use mod version 1.7.0, with separate Fabric and NeoForge artifacts. The existing 26.3 release is preserved byte-for-byte.

## Build and behavior checks

- Java 25.0.2. Each old support line passed `gradlew.bat --no-daemon clean test :neoforge:test releaseAllLoaders --console=plain`; final loader/NeoForge adapter adjustments also passed `test :neoforge:test releaseAllLoaders`.
- 56 tests per loader per support line: **224 tests**, zero failures, errors, or skipped tests on the final 26.1.x and 26.2 candidates.
- Packaged Fabric and NeoForge jars, rather than only development classpaths, were run on all four old Minecraft targets. Every entry below passed startup, runtime version/loader checks, config/validate/reload, invalid reload preserving both the file and last-known-good protection, and UTF-8 BOM validation/reload.
- NeoForge 26.1, 26.1.1, and 26.1.2 additionally passed an actual creative-mode dig packet: a placed stone block became air and the block-break callback completed without errors.
- Fabric requires Loader >=0.19.5 (bundled MixinExtras 0.5.5). Older Loader 0.19.4 starts but fails on player login because its MixinExtras 0.5.4 cannot read the new `@Redirect.at` array annotation.
- NeoForge 26.1.x supports both block-break event class names. Minimum loader metadata is `[26.1.0.19-beta,26.2)`; the jar is built against 26.1.2.30-beta and tested with 26.1.0.19-beta / 26.1.1.15-beta / 26.1.2.30-beta.
- The runner's protocol-775 configuration ping/pong slots were corrected against actual Minecraft source. Mojang `version.json` confirms that 26.1 / 26.1.1 / 26.1.2 all use protocol 775.
- Paper gate: `46d4834e8e2ec4af9dcfa028076fb16dfb8a3911`; no algorithm/default change needs a mod backport. See [Paper parity](paper-parity-status.md).
