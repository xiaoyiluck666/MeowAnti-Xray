# Meow Anti-Xray 1.7.0 更新日志

这是面向 Minecraft 26.2 的 1.7.0 版本。Fabric 与 NeoForge 分别提供安装文件，要求 Java 25。

- 与现有 26.2 / 1.6.0 保持反矿透功能一致，统一模组版本号。
- 保留 Minecraft 26.2 专用依赖、区块包适配与协议 776。
- 异步队列默认保持 16，旧配置可继续使用。
- Fabric 要求 Loader 0.19.5 或更新版本，确保实际联机时区块发送注入正常。

- 完成双 loader 单元测试、发布构建与实际安装服启动。
- 26.2 两端均通过 2 客户端 / 25 秒区块收发与重写检查，0 错误。
- 配置预检、正常重载、错误重载保留原保护及 UTF-8 BOM 检查通过。
