# Meow Anti-Xray 1.7.0

This release brings the 1.7.0 version line to Minecraft 26.2. Separate Fabric and NeoForge files are provided; Java 25 is required.

- Aligns the mod version while retaining the anti-xray features of 1.6.0 for Minecraft 26.2.
- Retains Minecraft 26.2 dependencies, chunk packet integration, and protocol 776.
- The default async queue remains 16; existing configurations remain supported.
- Requires Fabric Loader 0.19.5 or newer for compatible chunk-send mixin processing during player login.

## Validation

- Passed dual-loader unit tests, release builds, and standalone packaged-jar startup.
- Both loaders on 26.2 passed two-client / 25-second chunk delivery and rewrite checks with zero errors.
- Passed config preflight, reload, invalid reload preserving protection, and UTF-8 BOM checks.
