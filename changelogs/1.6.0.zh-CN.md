# Meow Anti-Xray 1.6.0 更新日志

这是面向 Minecraft 26.2 的维护与可观测性版本。

## 兼容性

- 更新 Fabric Loader、Fabric API 与 NeoForge 依赖到 26.2 线的较新版本。
- Fabric 与 NeoForge 的反矿透行为保持一致。

## 匿名统计

- 集成可退出的 bStats 匿名统计客户端，用于统计活跃服务器和基础运行时版本。
- 默认生成独立服务器 UUID，不收集服务器地址、名称、玩家名称或玩家 UUID。
- 统计配置位于 `config/meowantixray-bstats.properties`，设置 `enabled=false` 可关闭。

## 验证

- 完成 Fabric 与 NeoForge 单元测试、构建和启动兼容性检查。
- 保持异步队列默认值为 `16`，不因单次吞吐数据扩大内存压力。
