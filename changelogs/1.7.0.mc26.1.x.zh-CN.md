# Meow Anti-Xray 1.7.0 更新日志

这是面向 Minecraft 26.1 / 26.1.1 / 26.1.2 的 1.7.0 版本。Fabric 与 NeoForge 分别提供安装文件，要求 Java 25。

- 新增 `/antixray config` 生效配置摘要与 `/antixray validate` 只读预检。
- 重载前验证配置；失败时保留原文件及上次有效运行配置，支持 UTF-8 BOM。
- 同步性能诊断和可重复压测工具，异步队列默认保持 16。
- 同步可退出的 bStats 客户端；默认 `service-id=0`，尚未激活上报。
- Fabric 要求 Loader 0.19.5 或更新版本，确保实际联机时区块发送注入正常。
- 修复 NeoForge 26.1 / 26.1.1 的方块破坏事件兼容，避免因事件类改名导致启动失败。

## 验证

- 完成双 loader 单元测试、发布构建与实际安装服启动。
- 26.1、26.1.1、26.1.2 两端均通过 2 客户端 / 25 秒区块收发与重写检查，0 错误。
- 配置预检、正常重载、错误重载保留原保护及 UTF-8 BOM 检查通过。
- NeoForge 三个补丁版本均通过真实挖掘验证。
