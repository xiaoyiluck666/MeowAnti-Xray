# Meow Anti-Xray 1.7.0

This release brings the 1.7.0 version line to Minecraft 26.1, 26.1.1, and 26.1.2. Separate Fabric and NeoForge files are provided; Java 25 is required.

- Adds `/antixray config` for effective configuration and `/antixray validate` for read-only preflight checks.
- Validates before reload; invalid files and the last known good runtime configuration are preserved. UTF-8 BOM is supported.
- Updates pressure diagnostics and repeatable test tools; the default async queue remains 16.
- Includes the optional bStats client; submission remains inactive with the default `service-id=0`.
- Requires Fabric Loader 0.19.5 or newer for compatible chunk-send mixin processing during player login.
- Fixes block-break event compatibility on NeoForge 26.1 / 26.1.1 so the older event name no longer prevents startup.

## Validation

- Passed dual-loader unit tests, release builds, and standalone packaged-jar startup.
- Both loaders on 26.1, 26.1.1, and 26.1.2 passed two-client / 25-second chunk delivery and rewrite checks with zero errors.
- Passed config preflight, reload, invalid reload preserving protection, and UTF-8 BOM checks.
- All three NeoForge patch versions also passed an actual block-break check.
