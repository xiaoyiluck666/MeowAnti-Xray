# Meow Anti-Xray 1.6.0 Changelog

This is a maintenance and observability release for Minecraft 26.2.

## Compatibility

- Updated the Fabric Loader, Fabric API, and NeoForge dependencies to newer versions on the 26.2 line.
- Kept anti-xray behavior aligned between Fabric and NeoForge.

## Anonymous Metrics

- Added an opt-out bStats client for anonymous active-server and basic runtime version metrics.
- A separate random server UUID is generated; server addresses, names, player names, and player UUIDs are not collected.
- Metrics configuration is stored at `config/meowantixray-bstats.properties`; set `enabled=false` to disable it.

## Verification

- Completed Fabric and NeoForge unit tests, builds, and startup compatibility checks.
- Kept the default async queue at `16` instead of increasing memory pressure based on a single throughput sample.
